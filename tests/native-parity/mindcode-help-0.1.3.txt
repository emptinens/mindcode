MindCode native Rust foundation (multi-provider)

Usage: mindcode [PROMPT]...

Arguments:
  [PROMPT]...  Complete a chat request through the active provider

Options:
  -h, --help     Print help
  -V, --version  Print version

Commands:
  auth status       Show active provider authentication status
  model eligible    Inspect eligible Worker models of the active provider
  effort worker     Validate a Worker model and optional effort lock
  provider          Manage provider profiles (list, use, add, remove, edit)
  settings          Manage settings (show, key, allowlist, model, effort lock)
  setup-token       Show credential setup instructions
  doctor            Check native foundation health
  update            Show local checkout update instructions
  daemon            Run the native mindcoded daemon in-process
  tui               Run the native terminal interface
  chat              Complete a chat request through the active provider
